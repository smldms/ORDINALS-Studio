# Démarrer ORDINALS Studio

1. Télécharger ce dépôt et ouvrir `dist/index.html`.
2. Choisir l’un des six moteurs ; composer avec Réglages, Toile, Tracé et Affiche.
3. Dans Bitcoin, sélectionner les paramètres qui évoluent et leurs limites.
4. Prévisualiser les blocs via une passerelle ord autorisant CORS, ou utiliser la simulation hors ligne.
5. Charger un bloc réel ou Genesis, puis cliquer sur Exporter HTML.
6. Prévisualiser le HTML sur un serveur ord compatible avant inscription.

Le HTML est autonome ; aucune autre ressource du studio ne doit être inscrite. PLOTR Studio est un projet distinct.
